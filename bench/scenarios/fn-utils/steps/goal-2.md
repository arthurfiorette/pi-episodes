Back to the parser work. `ReturnType<typeof myFunction>` produces an empty/`any`-ish schema instead of the function's return type, for both `function` declarations and arrow functions. Also, functions with type predicates (`value is string`, `asserts value`) should be treated as returning `boolean` / `void`. And `Parameters<typeof fn>` only works for inline function types, not for `typeof` a declared function.

`Record<number, string>` is generated as `{ type: "array", items: { type: "string" } }`. The equivalent `{ [key: number]: string }` generates an object with `additionalProperties`. Both should produce the object form. Separately, a mapped type whose key constraint is `any` (`Record<any, string>`) throws `Unexpected key type "any" for this node`. Treating `any` keys as `string` would give a sensible `additionalProperties` schema.
